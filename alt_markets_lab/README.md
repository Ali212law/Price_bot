# آزمایشگاه بازارهای جایگزین (Alt Markets Lab)

این پوشه برای تست استراتژی‌های پروژه روی بازارهای غیرکریپتو (پیش‌بینی، سهام توکنیزه، فارکس و...) ایجاد شده است.

## اهداف
- کشف بازارهای جدید با پتانسیل سود
- بررسی سازگاری استراتژی‌های موجود (M9, Grid, LL) با این بازارها
- ایجاد سرمایه دانشی بدون ریسک مالی

## ساختار
- `prediction_market/` — تست روی Polymarket
- `tokenized_assets/` — تست روی سهام توکنیزه (در آینده)
- `cfd_brokers/` — تست روی فارکس/شاخص‌ها (در آینده)

## روش کار
1. دریافت داده تاریخی از بازار هدف
2. اجرای استراتژی‌های موجود (با حداقل تغییر) روی داده جدید
3. مقایسه نتایج با کریپتو
4. ثبت یافته‌ها در `DECISIONS.md`

## نکات مهم
- این آزمایشات **هیچ ارتباطی** با پرتفوی واقعی M11 ندارند.
- همه چیز در محیط Paper و روی داده‌های تاریخی است.
- هر بازار جدید نیازمند پیش‌ثبت‌نام جداگانه است.
